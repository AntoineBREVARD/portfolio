      Confidentialité & données

      Ce site est statique : il n'y a pas de serveur, pas de base de données, pas de traceur publicitaire ni d'outil d'analyse d'audience.

      • Aucun cookie n'est déposé.
      • Les boutons « Éditer » et « Ajouter une veille » écrivent uniquement dans le stockage local de ton navigateur (localStorage) — ces données restent sur ton appareil et ne sont jamais transmises.
      • Le formulaire de contact n'envoie rien à un serveur : il ouvre ton propre client mail avec un message pré-rempli, c'est toi qui l'envoies.
      • L'hébergement (GitHub Pages) peut journaliser des informations techniques standards (adresse IP, navigateur) selon la politique de confidentialité de GitHub, indépendamment de ce site.

      Une question sur tes données ? Écris à contact@example.com.
